What is in the box

Four shapes that do the work.

Your models, not ours

Add a provider key and the chat runs through it — Anthropic, OpenAI, Google, or any Open-compatible endpoint. There is also a model that runs in this tab over WebGPU, so a first answer needs no account and no network at all.

Projects, memory and skills

Chats belong to projects. Memory holds the things you want remembered across them, and skills are instructions you write once and switch on when you want them. The composer reads all three before it answers.

Extensions, and plugins that can act

An extension is a prompt add-on, or CSS and HTML drawn over the workspace itself — the Extension Maker builds it in place. Plugins reach GitHub, YouTube, Gmail and Drive, and every write stops for an approval card first. Nothing is sent anywhere without you seeing the call.

It stays on this machine

Chats, projects, memory, skills and keys live in this browser on this device. There is no Notal server to hold them, and signing in buys a name on a published card — not a backup. Clear the browser storage and it is gone, which is the point.
