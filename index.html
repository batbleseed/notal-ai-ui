What it is

Most AI chat apps are a server with a text box in front of it.

Your conversations live in someone else's database, the model is the one they bought, and the account is the product.

Notal AI is the other shape: a workspace that runs in your browser against models you bring yourself. Paste a key from Anthropic, OpenAI or Google, point at a local Ollama, use any Open-compatible endpoint, or switch on the small model that runs in this tab over WebGPU — which needs no account and no network at all.

Chats, projects, memory, skills and keys are written to this browser's storage on this device. There is no Notal server holding them, and no backup to fall back on. Clear the site data and the workspace is gone, which is the point.

The route

How a question travels.

  1. Assembled here

    Before anything is sent, the composer reads this browser: the active project's instructions, the memory you switched on, every extension that is on, and the plugin you named with @. That assembly happens locally; the provider only sees the prompt that comes out of it.

  2. One endpoint

    The prompt goes to exactly one place — the provider you configured. Your API key rides as a header on that request and is never sent anywhere else. Ollama goes to localhost:11434, so with it nothing crosses the network at all.

  3. Or nowhere

    Choose local ai and the answer is made on your own graphics card. A 0.5B Qwen downloads once, about 290 MB, and every call after that is served from the browser's own cache.

  4. Written down here

    The reply lands in the same storage blob as the rest of the chat. Nothing is uploaded to make it appear there, and searching your history reads those local records — it is not a query to anyone.

  5. Held before it acts

    Anything that changes the world — opening a pull request, posting a reply, writing a file — stops at an approval card that shows the call first. A plugin cannot act on an answer alone.

What is in the box

Four shapes that do the work.

Your models, not ours

Add a provider key and the chat runs through it — Anthropic, OpenAI, Google, or any Open-compatible endpoint. There is also a model that runs in this tab over WebGPU, so a first answer needs no account and no network at all.

Projects, memory and skills

Chats belong to projects. Memory holds the things you want remembered across them, and skills are instructions you write once and switch on when you want them. The composer reads all three before it answers.

Extensions, and plugins that can act

An extension is a prompt add-on, or CSS and HTML drawn over the workspace itself — the Extension Maker builds it in place. Plugins reach GitHub, YouTube, Gmail and Drive, and every write stops for an approval card first. Nothing is sent anywhere without you seeing the call.

It stays on this machine

Chats, projects, memory, skills and keys live in this browser on this device. There is no Notal server to hold them, and signing in buys a name on a published card — not a backup. Clear the browser storage and it is gone, which is the point.

Disclosed

What leaves your machine, and when.

WhereWhat goesWhen it goes
The provider you picked The assembled prompt, and the answer that comes back Only when you press send. The key is a header on that one request.
localhost:11434 The same prompt Only if you point a provider at Ollama. Nothing leaves the machine.
cdn.jsdelivr.net A request for the WebLLM engine and about 290 MB of weights Once, when you switch on local ai. Later calls read the browser's cache.
fonts.googleapis.com A stylesheet request and two font files On load of this page, the docs and the workspace. No content of yours is in it.
Firebase Your email address, a password hash, the verified flag Only when you sign in or register. Nothing is sent while you stay anonymous.
Supabase — the extension library Reads: the public cards. Writes: your name, a title, a description, a screenshot Only when you open the Library view, or publish. Never your chats or keys.
GitHub, Gmail, Drive and YouTube APIs Your token as a header, plus the query you asked for Only for an @github, @gmail, @drive or @youtube call, and only once you are connected to it.
A relay, if you typed one Device-flow codes for GitHub and Google; page reads for the browser companion Only if you put a URL in Settings. Left blank, those sign-ins simply do not complete — there is no default relay to fall back to.
Cloudflare Turnstile Nothing The captcha is written into the signup form but this build ships no site key, so it never loads.

Never leaves this device: your chats, projects, memory, skills, provider keys, attachments and history. They live in one localStorage blob as plain text, which means anyone holding your unlocked machine can read them. That makes this a privacy claim, not a security claim.

Quick start

Three steps, and none of them is an install.

01

Open the workspace

This tab is the app. No account, no download, nothing to sign up for.

02

Bring a model

Settings → Providers: paste a key, or use the address http://localhost:11434 for Ollama. Or switch on local ai and wait for the download.

03

Ask it something

Type @ to name a plugin, / for a skill, or nothing at all and it reads your project.

git clone https://github.com/batbleseed/notal-ai-ui.git cd notal-ai-ui && node server.js # then open http://127.0.0.1:4173/

Limits

Known gaps.

  • No desktop installer is published. The Windows build comes from studio-app/ in the repo — clone it and run npm run dist.
  • The browser companion is not on the Chrome Web Store. It loads unpacked from browser-extension/; a listing needs a paid developer account and a human review of its <all_urls> permission.
  • local ai is a 0.5B model. It answers, it summarises, it is not clever, and it needs a WebGPU-capable browser. On a machine without one the switch says so rather than pretending.
  • Plugins need accounts you own. A GitHub OAuth app with device flow enabled, a Google TV / limited-input client plus a secret on the relay, and a YouTube Data API key. Until those exist, @youtube reports itself as not connected.
  • Publishing takes an account and caps at ten extensions. Reading the library does not.
  • No sync, no backup. Two machines do not share a workspace, and there is nothing to restore from.
  • The plus in the box at the top of this page does nothing. It is the workspace's attach menu, drawn here so the box reads right. The real one is in the chat.
