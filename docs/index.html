01 · Getting started

Start here

Notal AI is a workspace for talking with AI models. Chats, projects, memory, skills and settings are saved in this browser, on this device. There is no Notal account to create and no server holding your history.

1

Open the workspace

Press Chat. You land in a new chat with the built-in model already selected.

2

Add a model

Settings → Providers. Pick a provider, type the model ID and your key, add it, then press Test on its row.

3

Make it yours

Start a project, write down what Notal should remember, save your best prompts as skills.

The built-in model is a demonstration.

notal generic answers from written templates so you can see the interface work. It is not a real language model, it cannot read a page, and it ignores memory and plugin calls. Add a provider key for real answers.

02 · The layout

The workspace, one piece at a time

Everything lives in one column, with the sidebar for getting around and the composer for doing the work.

The sidebar

New chat and Search are the first two buttons, then Projects, Memory, Skills, Extensions and Plugins switch the main column. Search opens a box that looks through every chat — by its title or by anything said in it — because the recent list below only ever shows the newest. The account button at the bottom opens Settings, where models, appearance and security live.

Chat and Coding

The switch in the top bar changes the system prompt and the four suggestion cards. Chat is for general conversation, writing and thinking. Coding is for code, bugs and technical answers: it leads with working code, names its assumptions, and points out failure modes. Your choice is remembered for the next visit, and the composer itself works the same in both modes.

The composer

From left to right: the + attach menu, the microphone, the model picker, and the send arrow. The arrow stays greyed out until there is text or an attachment to send, and becomes Stop while a reply streams. On a phone the composer is one row — plus, your words, the arrow — and the model picker moves to the top right of the page, so the microphone and the character count step out.

  • Attachments. Photos, videos, files and links. Dragging files anywhere over the chat brings up “Drop files into the chat” and attaches them when you let go. Each file can be up to 5 MB. Text files are read in — up to 12,000 characters each and 30,000 per message. Images travel to the model as images; videos and other binaries are listed by name only.
  • Dictation. In the browser, the mic uses Chrome or Edge's own speech service. In the desktop app it records and asks a Gemini model you configured to transcribe the audio.
  • The model picker. Shows what will answer the next message. Until you add a provider it reads notal generic.
  • Keys. Enter sends and Shift + Enter starts a new line. Esc closes a menu, a panel or Settings.

Reading answers

Replies are rendered as Markdown, including code blocks. Every code card carries its own Copy and Download. Click an attached image to open it full size. Right-click anywhere in the app (or long-press on a phone) for the app's own menu: Copy, Paste, Ask AI, and — with text selected — Make a new extension.

03 · Models

Talk to a real model

One key is all it takes. The model menu beside the send arrow lists everything you have added, and you can switch between them message by message.

Add a provider

Open Settings → Providers and follow the three steps on screen:

  1. Who answers. Pick Anthropic, OpenAI, Google Gemini, Ollama on this computer, or an OpenAI-shaped service of your own.
  2. Which model. Type the exact model ID the provider lists. For Ollama, it is the name it prints when the model is pulled.
  3. Add it, then check it. Adding puts it in the model menu. Press Test on its row: Notal sends one short message with your key, so a wrong key or model name shows up here rather than mid-chat.

Where the key goes

Keys are saved in this browser, not on a Notal server. A request goes from this tab straight to the provider you picked. Settings → General → Advanced → Diagnostics names the address Notal is actually using.

If the provider refuses the browser

Some services reject calls that come from a web page. A relay is a small forwarder you host yourself — the worker/ folder in the repo, or the one that ships inside Notal AI Studio. Open Settings → Providers → Advanced, paste the relay address, and press Test. Until that test is green, Notal keeps calling the provider directly.

Local AI, on this machine

Settings → Providers → Local AI · developer is off by default. Switched on, a 0.5B model joins the model menu and runs inside this tab on the graphics card through WebGPU. Its 290 MB of weights come down on the first question and stay cached by the browser. Nothing about the reply leaves the tab. It needs a browser with WebGPU — a recent Chrome or Edge.

04 · Context

Projects, memory, skills

These three buttons open sections in the main column. The chat stays behind them, so Esc or Chats brings you back with your draft untouched.

Projects

A project groups related chats. Give it a name, then press Open to make it active: new chats and new memories belong to it, and the top bar shows its name. Removing a project returns its chats and memories to General rather than deleting them.

Memory

Write down the facts you are tired of repeating. Each one can be scoped to General or to a project, and switched off without deleting it. Everything left on is added to the prompt of every real model call — the built-in template model cannot use it.

Skills

A skill is a saved prompt with a name. Use sends it right away; Insert puts it in the message box so you can fill in the blanks first. Skills are handy for review, summarising, and any instruction you type over and over.

05 · Extensions

Extensions

Extensions change how Notal answers and, if you want, how the page looks. The Extensions view lists built-in ones, yours, and the shared library.

Prompt add-ons

An instruction saved under Settings → Extensions. While it is switched on, its text rides along in every reply — “answer like a lawyer”, “always show the SQL first”. You can export one as JSON, import it on another device, and switch it off at any time.

UI extensions

A UI extension is CSS, HTML and JavaScript drawn over the workspace. Open Extension Maker in the Extensions view, write it, then use editor mode to drag and resize the piece on the page itself. When it looks right, download it or publish it. UI extensions run in this page with the page's own access, so only switch on ones you trust.

The library

Library shows extensions other people have published. Publishing from the Maker adds a card with your creator name and, if you add one, a screenshot; you can edit or withdraw your own entries, and one maker can keep up to ten published at a time. The library loads over the network, so a blank list usually means it could not be reached.

06 · Plugins

Plugins

A plugin lets Notal do something outside this page and report back what actually happened. Reading is free. Anything that changes something — a commit, a click, a sent message — stops and shows you a card first, and nothing runs until you press Approve.

PluginWhat it reachesWhat it needs
GitHub Repositories, issues and files; commits made through GitHub's API Sign in with GitHub. The device flow needs a relay, or Notal AI Studio's own relay.
Browser Your open Chrome tabs: read a page, follow a link, fill a field, press a button The Notal companion extension, from the Chrome Web Store or browser-extension/, with this page's address added in its options.
YouTube Real video search: titles, channels, dates and watch links A YouTube Data API key with YouTube Data API v3 enabled.
Gmail Read and search the signed-in mailbox; write a message you approve before it sends A Google OAuth client plus a relay holding the client secret, or a temporary token from Google's OAuth Playground.
Drive Find and read files; write plain-text files Notal made The same Google client, with Drive API switched on for it.

Typing @

Type @github, @browser, @youtube, @gmail or @drive in a message to name the plugin you mean. Switched-on plugins are already described to the model, and a mention makes it explicit: Notal must call that plugin before it answers, rather than just talk about it. Unknown mentions are left as ordinary text. In a new Coding chat, the Plugins tray under the composer opens a list and types the mention for you so you can keep writing.

Connecting and testing

Open Plugins in the sidebar, pick a cube, and follow its own setup steps. Each plugin has a Sign in button where it needs one and a Test button that reports what really answered. A plugin that is switched off, or still waiting for a token, is not offered to the model at all.

07 · Privacy

Privacy and security

Notal is local-first. The short version: your history is in this browser, and your keys go only where you point them.

Where your data lives

Chats, projects, memory, skills, models, extensions and preferences are stored in this browser on this device. There is no server copy to pull from: a different browser, a phone or an incognito window starts empty. Clearing this site's browsing data deletes all of it for good. The desktop build can save the open chat as Markdown; in the browser, export what you need before clearing anything.

Google sign-in

Signing in brings your name and profile picture to the account button and your messages. It does not upload or sync your chats, memory or API keys.

The PIN

Settings → Security puts a 4–8 digit PIN over the app, can lock it after idle, and locks instantly with Ctrl + Shift + L. The PIN screens the app — it does not encrypt it. Chats stay plain text in this browser's storage, readable by anyone who can open that storage.

Keys, tokens and relays

Provider keys and plugin tokens live in this browser. A key is sent only to the provider it belongs to, or to the relay you configured. A relay is yours: if you host one, your provider calls pass through it, so treat it like a server you trust with those requests.

Extensions run code

A UI extension can draw on the page and run JavaScript in it. That is what makes them useful, and it is why the only safe rule is: install and switch on what you trust.

08 · Look and install

Themes and install

Light, dark, or the device

Settings → Appearance offers three cards: Light, Dark and System. System follows your device and changes with it. The choice is remembered, and every panel, menu and code block follows it.

Install it like an app

Notal is a PWA. In Chrome or Edge, use the install button in the address bar (or Install app from the browser menu); on a phone, Add to Home Screen. It opens without browser chrome, and the app shell is cached so it still opens offline. Real answers still need a provider, or the local model after its first download.

The Windows build

studio-app/ turns the same workspace into a desktop app with a quick-chat overlay on a global shortcut, a tray icon, desktop notifications, its own local relay for provider calls and page reads, a skills.md file reread on every message, a native Save dialog, and dictation transcribed by your own Gemini model. No desktop installer is published yet — build it from the repo: studio-app on GitHub.

10 · When it does not

If something breaks

The answers look generic or repeat a template.

That is the built-in model. notal generic answers from written examples by design. Add a provider in Settings → Providers and pick it in the model menu.

A provider says it cannot be called from a browser.

Point Notal at a relay you host: Settings → Providers → Advanced, paste its address, press Test. The worker/ folder and Notal AI Studio both contain one.

GitHub sign-in will not finish.

Check that Device Flow is switched on for the OAuth app, and that a relay is configured — GitHub's token exchange cannot run in a browser tab on its own. Then sign in again and enter the code at github.com/login/device.

The Browser plugin says the companion is not answering.

Install the companion extension, add the address Notal is served from in its options, then reload this tab. A page only carries the bridge from the moment it loads. Finish with the plugin's Test button.

The extension library is empty.

It loads over the network. Check the connection and reload. If it still says it could not be reached, the shared library is unavailable rather than empty — your installed extensions keep working.

My chats disappeared.

They live in the browser that made them. A different browser or profile, a private window, or clearing site data starts from empty — there is no server copy to restore.

Does the PIN encrypt my chats?

No. It hides the app behind a screen. The chats stay plain text in this browser's storage. Use full-disk encryption or a separate browser profile if you need real protection at rest.

Can I use it offline?

The app shell is cached, so it opens offline. Answers need a provider connection, unless you have already downloaded the local AI model.
